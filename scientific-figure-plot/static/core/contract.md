# 绘图前契约与交付前质检验收规范 (Figure & QA Contract)

出版级顶刊科研配图本质上是一套严密的**视觉论证系统**，而非零散孤立的好看图表。每一幅图在编写代码和设计审美之前，必须建立明确的科学论点、证据层级以及同行评审风控标准；在交付导出前必须通过严格的质检验收。

---

## 1. 绘图后端首选项与选择规则
- 优先尊重当前任务明确指定的 Python 或 R 语言；
- 若未明确指定，动态读取已保存的首选项（本项目默认采用 Python 虚拟环境 `.venv` 解释器）；
- 严禁自行猜测或随意切换语言环境。

---

## 2. 后端排他性铁律 (Exclusive Backend Rule)
- 绘图语言一旦确立为 Python 或 R，该图件的所有绘图代码、预览图生成、最终出版级导出（PNG / PDF / SVG / TIFF）以及质检流程，**必须 100% 由该后端独立完成**；
- 严禁使用 Python 为 R 图表生成预览，也严禁使用 R 为 Python 图表生成替代码；
- 保证生成成果的完全可复现性与脚本归档的单一纯洁性。

---

## 3. 数据完整性红线 (Data Integrity Gate)
- 严禁为追求美观或计算提速而随意截断、过滤或减少观测样本；任何样本剔除（如 P99 异常值截断）必须具有明确的流行病学、生态学或统计学理论依据，并在方法学中精确记录过滤前后数量；
- 必须基于“科学结论”而非“数据源表格”来规划图件。多张中间数据表服务于同一个结论时，应在同一组图内系统呈现；
- 配对与异质性设计：当效应在配对样本或抽样层内产生时，必须重点可视化层内/配对差值变异（例如固定效应模型利用层内时变变异），严禁仅依靠混杂严重的总体边际分布。

---

## 4. 科研绘图五项黄金契约 (The Five-Point Contract)

在任何绘图代码落地前，必须在构思中锁定以下五项要素：

1. **核心结论 (Core Conclusion)**：
   写出一句话核心论点（该图件必须向审稿人证明什么假说或发现）。
2. **证据链布局 (Evidence Chain)**：
   将规划的每一个子面板（a, b, c...）与独特的推断问题映射；合并或删除仅仅重复展示相同证据的冗余子图。
3. **图件视觉原型 (Archetype)**：
   明确图件的宏观排版结构：
   - 定量网格图（Quantitative Grid）；
   - 概念/机制引导的复合图（Schematic-Led Composite）；
   - 图像与标本混合定量图（Image Plate + Quant）；
   - 非对称多模态组图（Asymmetric Mixed-Modality Figure）。
4. **技术规格与排版尺寸 (Layout & Geometry)**：
   - 严格执行单栏（约 88 mm）或双栏通栏（约 180 mm）物理宽度；
   - 最小字体不得低于 5 pt（确保缩小打印时清晰可辨）；
   - 包含图元碰撞检测、真实空间投影（地图强制 `set_aspect('equal')`）、可编辑文字保留。
5. **统计学与不确定性规范 (Statistics & Uncertainty)**：
   - 误差棒、阴影置信区间、中心度量（均值/中位数）、离散度（IQR/SD/SE/95% CI）必须具备完整的数学与医学定义；
   - P 值、显著性等级、真实安全阈值（TMREL）必须标定清晰。

---

## 5. 出版前终审质检验收清单 (Pre-Submission QA Checklist)

在最终导出图片、向导师汇报、准备修回（Revision）或正式向期刊提交前，必须逐项核对本清单：

| 质检维度 | 严格合格条件 | 违规典型问题 (不合格) |
| :--- | :--- | :--- |
| **核心结论** | 具备一句话科学论点，且每个子图都明确映射到该论点上 | 图表堆砌，不知道每幅子图究竟要说明什么结论 |
| **版面原型与层级** | 具有清晰的图件原型，主证据面板（Hero Panel）视觉层级突出 | 机械均分的九宫格，各子图权重无主次之分 |
| **后端单一纯洁性** | 所选后端 (Python 或 R) 独力完成绘图、预览与导出 | 混合调用或依赖跨语言临时图 |
| **印刷物理尺寸** | 单栏宽 **`88–89 mm`**，双栏宽 **`180–183 mm`**，高度不突破版心极限 (230 mm) | 随意设置 16:9 或无尺寸概念导致缩放后模糊变形 |
| **正文字体大小** | 图中正文、刻度文字、轴标签在最终物理尺寸下为 **`5–7 pt`**，图号 9pt 加粗 | 字号过大像儿童读物，或低于 5pt 导致打印时完全看不清 |
| **子图编号格式** | 加粗置于左上角，**仅标注编号**（如 `a`, `b`, `c`） | 在子图内部正上方硬塞一长串冗长英文主标题 |
| **字体家族一致性** | 全图严格统一使用无衬线字体：**`Arial`** (或 `DejaVu Sans` / `Helvetica`) | 图内混用 Times New Roman、宋体、黑体或楷体 |
| **色彩与色盲友好** | 杜绝彩虹色阶 (Jet)；红绿不作为唯一区分通道；灰度打印仍可分辨 | 依赖红绿对比，或采用刺眼的高饱和原色 |
| **图例与标注精简** | 尽量使用就近直接标注 (Direct Labels) 或多图共享图例；消除重复图例 | 每个子图右侧都重复贴出相同的冗长图例框 |
| **统计信息完整性** | 明确注明样本量 $n$、中心度量、离散度（SD / SE / IQR / 95% CI）与精确 P 值 | 只有孤零零一条折线或无置信区间的柱体 |
| **地图几何投影比** | 空间矢量地图强制锁定真实物理长宽比：**`ax.set_aspect('equal')`** | 地图被纵向拉长（大洲变细长）或横向压扁变形 |
| **图元防碰撞安全** | 标签文字与数据散点、拟合曲线、误差棒之间留有安全间距，无重叠遮挡 | 文字盖在数据点或误差线上，互相重叠涂抹 |
| **高分辨率导出** | 默认导出 **300+ DPI PNG**；用户显式要求时再导出矢量 PDF/SVG | 截图导出、72 DPI 模糊图，或文字被转为点阵栅格 |

---

> **最高原则**：**图件服务于科学逻辑**。视觉打磨、配色调整与排版技巧，必须全面从属于使核心结论严谨、可防御、经得起审稿人挑剔检验。
