## 第二部分：形式化规格说明与审查边界 (Specs & Invariants) 【★ 核心审查防线】

### 1. 输入前置条件预检 (Input Pre-conditions)
- **必须存在的列与类型**：列出 DataFrame 必须包含的字段及对应 `dtype`。
- **值域合法性检查**：例如经度 $\in [-180, 180]$，纬度 $\in [-90, 90]$，样本权重 $> 0$。
- **空值容忍度**：核心自变量/因变量缺失值必须明确为 0 容忍（前置过滤）或指定填充算法。

### 2. 数理转换与算法不变性 (Mathematical Invariants)
- **严格数学公式**：写出聚合或加权算法公式（如 $\bar{E}_j = \frac{\sum E_i \cdot w_i}{\sum w_i}$）。
- **异常值截断时机与口径**：
  - 明确截断算法（如上界 P99 截断）；
  - 明确分位数计算范围（全局非空子集计算 vs 分国别计算）；
  - 明确截断策略（替换为阈值上界 vs 直接丢弃行）。
- **空间几何不变性**：若含地图空间操作，明确投影坐标系（WGS84 EPSG:4326）与裁剪掩膜边界。

### 3. 反向红线与禁止项 (Negative Constraints / MUST NOT)
- **严禁原位篡改**：严禁修改或覆盖原始输入数据文件；
- **严禁静默过滤**：因空值或异常被过滤的样本，必须在终端日志中明确输出剔除行数统计，严禁无声丢弃；
- **绘图脚本禁止计算**：绘图脚本严禁调用 `scipy`、`statsmodels` 或 `survival` 计算 P 值、标准误或拟合参数，必须 100% 消费中间表；
- **纯英文日志输出**：代码内部的所有 `print()`、`logging`、异常提示 100% 使用英文，禁止输出中文终端日志；
- **地图长宽比锁死**：地理矢量地图轴必须显式设置 `ax.set_aspect('equal')`。

### 4. 产出后置断言契约 (Output Post-conditions)
- **Schema 对齐断言**：输出表列名与数据类型必须 100% 匹配设计契约；
- **非空断言**：输出中间表的关键分析字段必须 `notnull().all()`；
- **数量级自验**：输出行数必须符合预期数量级区间（如集群数 $N \approx 44,000$）。
