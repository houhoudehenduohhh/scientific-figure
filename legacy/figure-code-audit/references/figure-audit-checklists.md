# 顶刊科研绘图代码审计清单 (Figure Code Audit Checklists)

本清单定义 `figure-code-audit` 调度的 3 个独立纯净 Subagent 针对绘图草稿代码实施多维度审计的硬性核验准则。

---

## Subagent 1: 契约与统计规范审计员 (Contract & Statistics Auditor)
**核心职责**：核验代码对 `code_spec.md` 数据契约的消费真实性及反向红线遵守情况。

1. **中间表消费契约**：
   - [ ] 是否严格从 `Dataset/` 中读取标准 Tidy 结果表？字段名（`estimate, se, ci_lower, ci_upper, p_val, n` 等）是否与契约 100% 对齐？
   - [ ] 是否存在硬编码统计数字或临时伪造数据的行为？
2. **反向红线 (Negative Constraints)**：
   - [ ] **严禁现场计算统计模型**：代码中是否违规引入 `scipy.stats`、`statsmodels` 或 `survival` 临时重算 P 值、回归参数或显著性？
   - [ ] **严禁静默过滤**：是否存在隐式 `dropna()`？被过滤的行数是否有显式终端日志输出？
   - [ ] **日志语言规范**：所有 `print()` 与 `logging` 是否 100% 为纯英文？是否存在中文字符污染终端？
3. **数理标度映射**：
   - [ ] 风险比（HR / OR / RR）是否采用对数标度（Log scale）或对数变换？无效应基准虚线是否准确标注于 $1.0$（比值类）或 $0.0$（差值/Beta类）？
   - [ ] 误差棒与置信带映射逻辑是否与蓝图完全一致？

---

## Subagent 2: 期刊版式与排版拓扑审计员 (Layout & Typography Auditor)
**核心职责**：对照 Nature 期刊物理技术规格，审计图幅尺寸、字体字号与几何防碰撞。

1. **图幅物理尺寸**：
   - [ ] 图幅宽度是否严格限制为 88 mm（单栏）、120 mm（1.5 栏）或 180 mm（双栏）？
   - [ ] 转换为英寸时计算是否精确（如 $88\text{ mm} \approx 3.46\text{ inches}$）？是否预留合理边缘留白？
2. **底层排版与字体字号规范**：
   - [ ] 全局字体是否显式设置为 `Arial` 或等价无衬线字体？
   - [ ] Panel 标号（a, b, c）是否为 9 pt 加粗（Bold）？
   - [ ] 坐标轴标题与图例标题是否为 7 pt？刻度标签与正文标注是否为 5–6 pt？
   - [ ] **物理底线**：是否存在任何小于 5 pt 的文字、下标或注释？
3. **坐标轴与线宽规格**：
   - [ ] 边框与轴线宽是否严格为 0.5 pt？
   - [ ] 刻度线是否强制向内（Inward）？主刻度长度是否在 2.5–3.0 mm、次刻度 1.5 mm？
4. **空间拓扑与视觉防碰撞**：
   - [ ] 地理空间矢量轴是否强制执行 `ax.set_aspect('equal')`？
   - [ ] 散点、误差棒、图例文本之间是否存在碰撞重叠隐患？

---

## Subagent 3: 代码鲁棒性与任务断言审计员 (Robustness & Assertions Auditor)
**核心职责**：核验 OpenSpec Tasks 落地完整性、程序化断言有效性与防御性退出。

1. **原子任务覆盖度 (Tasks Coverage)**：
   - [ ] 代码结构是否完整映射了 `code_spec.md` 中规划的 Task 1 至 Task 4？
   - [ ] 是否遗漏了任何核心数据预检、美化或导出步骤？
2. **程序化断言 (Verification Assertions)**：
   - [ ] 前置断言：是否包含输入文件存在性与必需列集断言（`assert input_path.exists()`）？
   - [ ] 过程断言：是否对关键数值范围或样本非空实施断言？
   - [ ] 产出断言：是否断言图片导出成功且文件大小非空（如 `assert fig_path.stat().st_size > 10000`）？
3. **技术防御与资源释放**：
   - [ ] 是否显式调用 `plt.close()` 释放绘图句柄与内存？
   - [ ] 异常处理是否完备？遇到致命错误时是否调用 `sys.exit(1)` 退出并打印英文错误说明？
   - [ ] 导出格式与 DPI 是否达标（默认 300+ DPI PNG）？
